商業模式圖產生器 — 操作手冊

這是做什麼的？

商業模式圖（Business Model Canvas，Alexander Osterwalder 提出的經典九宮格框架）是一頁式呈現一個商業模式全貌的工具。本工具填一次商品資訊，就能自動先幫你把九宮格填好草稿，之後直接在格子裡點擊就能修改——manual-first 設計，AI 只是幫你加速起點，不是取代思考。

九宮格的九個欄位

欄位在問什麼
關鍵合作夥伴誰是你不可或缺的外部夥伴／供應商？
關鍵活動要做好這個商業模式，你每天必須做的核心事情是什麼？
關鍵資源你需要什麼資產、技術或團隊才能運作？
價值主張你到底幫客戶解決了什麼問題？為什麼是你？
顧客關係你怎麼跟客戶互動、維持關係？
通路客戶怎麼知道你、怎麼買到你？
客戶群體你到底在服務誰？
成本結構錢主要花在哪裡？
收益流錢從哪裡來、怎麼賺？

基本流程

  1. 填寫產品/服務名稱、產業類別、目標客群、核心痛點（或按下方按鈕載入範例）
  2. 按「✨ 產生九宮格草稿」，系統會依產業判斷（健康科技/餐飲食品/軟體服務/生活家電/教育內容/一般消費）套用對應模板，同樣的輸入永遠得到同樣的草稿
  3. 直接點擊任一格內文字即可編輯——這是本工具的核心，草稿只是起點，你的修改才是最終版本
  4. 對某一格的版本不滿意，按該格右上角「🔄」單獨換一個版本，不影響其他格子
  5. 想要更貼合實際情況的內容，可以填 API 金鑰後按「🤖 請 AI 生成完整九宮格」（會覆蓋目前內容，請先確認）
  6. 完成後可複製全部文字、下載 .txt，或直接列印/存成 PDF

要不要填 API 金鑰？

不填完全不影響使用——規則式草稿零金鑰即可產生完整九宮格。金鑰只用於「請 AI 生成完整九宮格」這個選用功能，會依你實際填寫的產業/客群/痛點描述生成更貼合情境的內容。金鑰只存在你瀏覽器的 localStorage，本工具不會經手或保存。

⚠️ 本工具產出內容僅供商業模式發想參考，不構成投資或經營決策建議；規則式草稿是套版文字，AI 生成內容也可能有誤，請自行查證與修改後才適合正式使用。

填一次商品資訊，九宮格自動先幫你填好草稿，直接在格子裡點擊修改——manual-first 設計，AI 只是加速起點

1. 商品／服務基本資料

「產生九宮格草稿」是規則式引擎，不需要金鑰，同樣的輸入永遠得到同樣的草稿；每格右上角 🔄 可以單獨換一個版本。「請 AI 生成完整九宮格」需要在右上角填入 API 金鑰，會依你的實際描述重新生成更貼合的內容（會覆蓋目前九宮格內容，請先確認）。

2. 商業模式九宮格

API 金鑰設定（選用，BYOK）

不填也能用——規則式草稿完全免金鑰。填金鑰後可以用「請 AI 生成完整九宮格」取得更貼合你實際描述的內容。金鑰只存瀏覽器 localStorage。

使用警語
  • 本工具產出的九宮格內容僅供商業模式發想參考，不構成任何投資或經營決策建議，請自行評估市場實況。
  • 規則式草稿是套版文字（依產業分類挑選模板），AI 生成內容則可能有誤，兩者皆需自行查證與修改後才適合正式使用。
  • 填有 API 金鑰時會直接連線到你選擇的服務商，該金鑰只存在你的瀏覽器，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用。
  • 請勿輸入真實機密商業資料；所有欄位只存在你瀏覽器的 localStorage，不會上傳到任何伺服器。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
